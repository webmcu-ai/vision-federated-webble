Vision Federation WebBLE Hub v001

Connect several XIAO vision nodes and watch the local Edge AI network. Each XIAO trains its own model. The XIAOs perform the federated learning directly between themselves.

Federated Learning

No XIAO nodes connected yet.

The intended flow is:

1. Each XIAO collects local images.
2. Each XIAO trains locally.
3. XIAOs discover nearby peers.
4. One XIAO becomes coordinator.
5. Local models are pulled together.
6. FedAvg creates a shared model.
7. The shared model is pushed back to the peers.
8. Nodes continue with inference.

The browser is the monitor and control panel.
The XIAOs perform the federation.
